# Little Legion Games – Webseite

Impressum und Datenschutz für die Spiele von Little Legion Games.
Wird aus den Spiel-Repos erzeugt, hier nicht von Hand bearbeiten:

- `built-in-a-day/` – aus dem Repo built-in-a-day (`node scripts/build-site.mjs`)
- `survival/` – aus dem Repo Survival_prototype (`npm run site`, Ausgabe `site-dist/survival/`)
